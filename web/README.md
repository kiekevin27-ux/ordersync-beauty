# Glowra Store (toko demo)

Toko demo fiktif untuk studi kasus OrderSync Beauty. Checkout dikirim ke workflow n8n 03 lalu tercatat di Google Sheets.

```powershell
npm install
copy .env.example .env.local   # isi N8N_WEBHOOK_URL
npm run dev                    # http://localhost:3000
```

Panduan lengkap, alur, dan skenario demo: [`../docs/06-toko-demo-website.md`](../docs/06-toko-demo-website.md).
